[DOC-01]
Title: Purpose
The Smart Website Monitoring Agent checks a website and determines whether its content has changed compared with a previously saved snapshot.

[DOC-02]
Title: Website Monitoring
The agent retrieves the website content and extracts the readable text. The extracted text is compared with the previous saved snapshot.

[DOC-03]
Title: Baseline
If no previous snapshot exists, the current website content is saved as the baseline. The system reports that the baseline has been created.

[DOC-04]
Title: No Change
If the current website content is identical to the previous snapshot, the system reports that no changes were detected.

[DOC-05]
Title: Change Detection
If the current website content differs from the previous snapshot, the system reports that a website change was detected and saves the new content as the latest snapshot.

[DOC-06]
Title: Snapshot
A snapshot is a saved representation of the website content used as a baseline for future comparisons.

[DOC-07]
Title: CrewAI
The Week-5 implementation used CrewAI to organize the system using an Agent, Task, Crew, and Tool. The website monitoring operation remained inside a dedicated tool.

[DOC-08]
Title: RAG
Retrieval-Augmented Generation (RAG) allows an agent to retrieve relevant information from a knowledge source before producing an answer. Retrieval can provide information beyond the model's immediate context.

[DOC-09]
Title: Grounding
A grounded answer is an answer supported by information retrieved from the knowledge source.

[DOC-10]
Title: Citation
A citation identifies the knowledge source used to support an answer.

[DOC-11]
Title: Retrieval Evaluation
The Week-6 evaluation measures retrieval hit rate, answer correctness, and citation correctness separately.
