# System Architecture

The following diagram illustrates the flow of a request from the user to the agent and back, along with the CI/CD evaluation pipeline.

```mermaid
graph TD
    %% User Interaction
    Client([Client / User]) -->|POST /chat| API[FastAPI Service]
    
    %% Security & Agent
    API -->|Validate Query| Guardrail[Security Guardrail]
    Guardrail -->|Safe Query| Agent[Secure Agent]
    Guardrail -.->|Block Injection| API
    
    %% RAG Process
    Agent -->|Retrieve| KB[(Knowledge Base)]
    Agent -->|Generate| LLM[Ollama / Llama 3.1:8b]
    LLM -->|Draft Answer| Agent
    
    %% Response
    Agent -->|Final Answer| API
    API -->|JSON Response| Client
    
    %% CI/CD Pipeline
    subgraph CI/CD Pipeline (Week 11)
        Tests[Test Suite: Capability, Safety, Regression] -->|Run| Graders[Dual Graders]
        Graders -->|Check Thresholds| CI{GitHub Actions}
        CI -->|Pass 100%| Merge[Allow Merge]
        CI -->|Fail < 100%| Block[Block Build]
    end
    
    %% Database and Pipeline connection
    KB -.->|Evaluated by| Tests
